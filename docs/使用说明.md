# MiniMax-H3 使用说明

> 面向已经跑完 `install.ps1` 的完整操作手册。
> 下文假设 ComfyUI 装在 `C:\ComfyUI_windows_portable`，装在其他盘请自行替换路径。

---

## 我该点哪个？

| 想要 | 双击 |
| --- | --- |
| 做一条完整片子（多段接起来、每段还能各配一张图） | **MiniMax-H3 一键出片** ← 推荐，全中文表单 |
| 用「人物/道具/场景参考图」生成，让画面和参考图长得一样 | **MiniMax-H3 参考图出片** |
| 懒得写提示词、想要 1~2 分钟长片 | **MiniMax-H3 制作长视频**（问答式） |
| 只想随便试一段、想自己调参数 | **MiniMax-H3 启动** → ComfyUI 网页界面 |

---

## 一、一键出片（最简单，推荐）

双击桌面「MiniMax-H3 一键出片」，浏览器会自动打开一个中文表单：

**① 全局提示词（整片统一）**

整条片子要保持一致的东西写这里：人物长相/服装、场景、画风、光线、镜头风格、声音氛围。每一段都会自动带上它。

**② 每一段拍什么（每段都能配图）**

- 每段左边那个方块 = 这一段的配图（点一下选文件，或者把图片直接拖进去；不放图也行）
- 第 1 段的图 = 视频从这张图开始演（图生视频）
- 第 2 段起，每段可以选两种拍法：
  - **「接着上一段演」**：一镜到底的感觉。这时如果配了图，这一段的结尾会演到那张图为止（适合控制结尾画面）
  - **「用图另起一段」**：这一段从这张图重新开始，段与段之间会切换（像分镜故事板，必须给它配一张图）
- 每段都要写提示词：**在哪里 + 谁在做什么 + 镜头怎么动 + 什么声音**
- 点「＋ 加一段」加第 3、4 段……（单段最长 15 秒）
- 不会写就点「填入示例」看范例

**③ 设置**

| 项 | 说明 |
| --- | --- |
| 每段时长 | 3~15 秒（越长越慢） |
| 画质 | 快 / 标准 / 清晰（8GB 显存建议"标准"） |
| 画面比例 | 横屏 16:9 / 竖屏 9:16 / 方形 |
| 接缝处理 | 柔和过渡（推荐）/ 硬切 |

然后点「开始生成」，界面会实时显示进度和预计剩余时间。跑完自动出现播放器，可直接看、另存为、打开文件夹。

> 成片会自动保存一份到 `C:\Users\<你>\Downloads`。
> 实测：2 段 × 5 秒（约 8 秒成片）= 3 分 10 秒。

## 二、提示词和配图怎么写

- 每段写四件事：**在哪里 + 谁在做什么 + 镜头怎么动 + 什么声音**
- 全局提示词 = 所有段都一样的东西
- 实测好用的例子：
  - 全局：`写实电影质感，同一位穿蓝色冲锋衣的年轻女子，黄昏的海边，35mm 镜头，自然光，画面稳定清晰，环境声连续。`
  - 第 1 段：`黄昏的沙滩上，她慢慢向前走，海浪在身后翻滚，镜头缓慢推近，海鸥声和浪声。`
  - 第 2 段：`她停下脚步望向海面，夕阳更低了，镜头继续缓慢推近到侧脸，风声浪声持续。`
- 配图的用途：
  - 想从某张照片开始动 → 把图放在第 1 段
  - 想让某个画面出现在结尾 → 放在后面某段（保持"接着上一段演"）
  - 想每段一张图、各自成段 → 后面每段选「用图另起一段」
- 配图小技巧：图片比例和你要生成的比例（横屏/竖屏）接近，效果最好
- 镜头运动直接写：`缓慢推近 / 左摇 / 航拍 / 手持`
- 想让人物说话：把台词用引号写进提示词

## 三、参考图出片（人物 / 道具 / 场景 长得像你给的图）

双击桌面「MiniMax-H3 参考图出片」：

**① 自动打开记事本**，里面是这次要演的提示词。想让模型演什么，改这个文件 → 保存 → 关掉记事本。

格式是 H3 官方的六段式：

```text
subject_definitions:    # 角色/道具/场景定义，用 <Picture N> 指代参考图
summary:                # 一句话总览
retention_analysis:     # 哪些要素必须保持一致
detailed_description:   # 镜头与逐秒分镜，[0s-1s] 这样写
overall_soundscape:     # 环境音、音效、人声
non_diegetic_music:     # 背景音乐（要求"不要 BGM"就写 None）
```

**② 回到黑窗口回答三个问题**：几秒（1~15）/ 清晰度（1 预览 2 标准 3 最高）/ 要不要 60fps 插帧。

**③ 等它跑完**，成片自动存到「下载」文件夹并打开所在文件夹。

**参考图在哪、怎么换？**

```
C:\ComfyUI_windows_portable\ComfyUI\input\
    ref_face.png    人物脸（<Picture 1>）
    ref_body.png    人物全身（<Picture 2>）
    ref_sword.png   道具/武器（<Picture 3>）
    ref_scene.png   场景（<Picture 4>）
```

换成自己的图、用一样的文件名覆盖即可。想换数量：编辑 `h3-studio\run-ref-shot.ps1` 的 `-RefImages` 参数。

**实测**：832×480 / 12 秒 / 20 步 / 4 张参考图 = 17.5 分钟。

**小贴士**

- 参考图会自动缩到跟画面一样大；想要最像，参考图尽量清晰、正脸、背景干净
- 画面太暗 → 在提示词里加：`人物是画面里最亮的部分，月光在他脸上形成明亮的主光，皮肤曝光正常，不要压成死黑`
- 生成完可以再调亮 / 锐化 / 补插帧：

```powershell
cd C:\ComfyUI_windows_portable\h3-studio
python h3_post.py 视频.mp4 --brighten 1.35 --sharpen 0.8 -o 出片.mp4
```

## 四、ComfyUI 界面（进阶）

双击「MiniMax-H3 启动」→ 左侧「工作流」里选：

- **MiniMax-H3 文生视频（8G显存）**：单段文字生成，最清爽；turbo 开关已默认开启（4 步）
- **MiniMax-H3 多段图生视频（全局+分段提示词）**：多段 + 图片，配合 H3 Segment Prompt 节点按段自动选提示词

在画布中间最大的节点上填 prompt，点右上角「运行」。

## 六、常见问题

**Q: 提示显存不足 / 跑到一半卡住？**
把「画质」调成"快"、「每段时长」调短；关掉游戏和多余浏览器标签页。

**Q: 网页打不开 / 一直转圈？**
再双击一次「MiniMax-H3 一键出片」，它会自己把服务拉起来（ComfyUI 没开也会自动拉）。

**Q: 生成的视频在哪？**
自动保存到 `C:\Users\<你>\Downloads`（下载文件夹）；界面上的「打开所在文件夹」也直接打开那里。原始文件另有一份在 `C:\ComfyUI_windows_portable\ComfyUI\output\h3_studio\`。

**Q: 提示"第 N 段选了用图另起一段，但还没有配图"？**
给它放一张图，或把该段改回「接着上一段演」。

**Q: 每次出的片子都不一样？**
正常，是随机的。想复现就在脚本里固定 seed。

**Q: 能商用吗？**
脚本 MIT；模型权重和生成内容的商用条款见 MiniMax-H3 官方许可。
